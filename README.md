## Entry

> I'm out of the office permanently — I quit to pull espresso shots. Your ticket is now a latte order. If it's urgent, add oat milk. If it's not urgent, it was never urgent. I'll reply when the milk steams, not before.

## How it works

`main.ts` assembles the reply from five short beats (resignation, new job, ticket-to-latte reframe, urgency rule, sign-off), checks the 1–280 character gate, and writes it to `<outDir>/entry.txt` with no trailing newline.
